# Paper source

`main.tex` is the paper entry point. The source uses the ICASSP `spconf` layout and keeps the method, theory, experiments, and conclusion in `sections_rl/`. Figures are stored in `figures/`, generated table fragments in `generated/`, and the bibliography is `references_rl.bib`.

The checked-in PDF is a private reference build and may contain author metadata that must be finalized before public release.
