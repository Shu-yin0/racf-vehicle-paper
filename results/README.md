# Results and paper crosswalk

This directory contains compact, paper-facing summaries. The original worker-level traces and large raw result shards remain private and are not required for the public smoke gate.

- `smoke/`: deterministic synthetic smoke output generated by `python scripts/reproduce.py`.
- `conditional_coverage_v17.json`: coverage summary used for the paper evidence review.
- `safety_followup_v2_analysis.json`: compact safety analysis summary.
- `safety_iid_v4_analysis_holm.json`: multiple-comparison analysis summary.
- `policy_ensemble_v16_analysis.json`: policy-family analysis summary.
- `table*.tex`: compact manuscript table fragments.

For the complete mapping from paper figures/tables to scripts, see [`REPRODUCE.md`](../REPRODUCE.md).
